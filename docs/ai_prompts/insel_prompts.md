# AI-Bild-Prompts pro Insel

Generiere mit DALL·E / MidJourney / Stable-Diffusion. Lege fertige PNGs
ab unter `assets/images/islands_composite/<id>.png`, 512×512 px,
transparenter Hintergrund. Lizenz in ASSETS.md ergänzen.

## Base-Style-Prompt (immer voranstellen)

> isometric 2:1 perspective, cartoon style, vibrant cel-shading, soft
> shadows, transparent background, no text, square aspect ratio,
> child-friendly art

## Tipps

- Generiere 3-4 Variationen pro Insel, wähle die beste
- Achte auf transparenten Hintergrund (Prompt: "transparent background"
  + Post-Processing: Hintergrund per `rembg` rauslöschen)
- Konsistenz: alle Inseln im gleichen Iso-Winkel, gleiche Beleuchtung
- Skaliere/croppe auf 512×512, sichere als PNG
